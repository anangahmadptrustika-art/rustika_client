# Public assets

Place static files served at the site root here.

## Brand logo

Upload the company logo as **`logo.png`** in this folder
(`public/logo.png`). It is used for:

- the in-app logo (sidebar, header, login, client portal)
- the browser tab icon (favicon)

Until `logo.png` is present, the app shows a built-in monogram fallback,
so the UI never displays a broken image.

Recommended: a square-ish PNG with a transparent background, at least
256×256 px.
